# 冒险50关首周目／重玩规则检查

`AdventureRulesRuntime` 对1..50关分别运行首周目和重玩，各以100、30、240Hz及不规则纳秒步长推进，共400个真实Board场景。本轮未发现新的生产代码缺陷。

每项核对场景背景、波数、阳光、行数和传送带／选卡路由；开场Board时间不推进，进入战斗才推进，普通暂停再次停止。前期首周目的一／三／五行限制、4-5夜晚背景与三轮15／20／25罐、2-5九个墓碑及樱桃救场卡、3-5半尺寸僵尸、最终僵王行号单独检查。

前两关通过真实`SeedPacket::MouseDown → Board::MouseDownWithPlant`种植，实际等待7.6秒冷却后再次操作，完成两株豌豆／三株向日葵教学链。资金置1000以隔离教学状态与攒阳光；仍检查真实扣费，不声称测试赚取这些阳光。传送带缩短首次等待，再检查真实卡片到达。普通关经实际出怪调度器刷出第一波并检查行号；僵王经真实入场入口创建，测试不重复其全部攻击（另见僵尸目录）。

各关末尾清掉旧敌人和罐子、构造末波已完成，再让真实末敌死亡触发`TrySpawnLevelAward`，核对首周目新植物／工具／纸条／银向日葵，以及重玩钱袋与保留纸条的例外。新植物奖励还检查具体SeedType。未执行奖励拾取后的应用界面跳转，不把这一检查写成连续打通50关。

## 1073证据

`extract.py`先核对英文GOTY 1.2.0.1073发行EXE的SHA256，再只读提取：

- `0x722CD0`：50关原始波数表，与测试预期逐值相符。
- `0x40BC79..0x40BCEB`：按关卡查表，重玩时非小僵王关少于10波则改20，否则增加10；砸僵尸8波特例位于该块之前。
- `0x456F60`：每区八种新植物与第5／10小关奖励空位的计算。
- `0x540950..0x540A0F`：9／19／29／39／49关纸条优先；首周目4、14、24、34、44关工具，50关银向日葵，普通关新植物；重玩钱袋在共享分支`0x540AA1`。

反汇编保存为`retail-disassembly.txt`。这些是规则证据，不是原版整局执行结果。

初始非传送带选卡直接填合法卡槽；没有复验每关选卡UI。4-5三轮布局由实际清场／填充入口依次构造，没有验证戴夫对白点击和自动换轮全过程。测试跳过中间战斗、最终boss战及奖励后续页面，不涵盖全部战术组合。图像／植物／僵尸／小游戏／解谜／生存的独立目录提供相应补充，不能用本项替代它们。

最初夹具在僵王尚未创建时强行运行传送带，触发`GetBossZombie()`空指针；真实开场会先创建僵王。已按实际顺序修正夹具，没有为此添加生产兜底或把夹具错误登记为游戏bug。

定向入口：`tools/test-image-runtime.ps1 -BuildDirectory out/x64-win32-vulkan -Case adventure-rules -OutputDirectory $env:TEMP/pvz-adventure-rules-runtime`。`capture.py <log> <test-exe> <pak>`要求完整图像套件也通过，核对400个唯一组合及8项教学结果，保存源码／exe／PAK哈希。所有文件写入Temp私有用户目录，不修改玩家进度，不产生性能结论。
