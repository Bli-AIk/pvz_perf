# Android 原生触控与独立鼠标验证

本轮输出为 v3.2.5 触控测试包，不是新的发行版。DAT64 仍为 v4，触控捕获、按钮目标及选中状态均不写入存档。Windows 使用 Preview 输出，未替换正在运行的 Release 程序。

## 自动化结果

`touch-input.log` 链接当前 Windows 生产对象，读取实际 PAK，检查：

- 用户列表无鼠标悬停时可选择；鼠标停在另一项时仍按触点坐标选择；空白和滚动偏移正确。`list-before-fix.log` 保留修复前实际失败结果。
- 真实 ButtonWidget 在没有中间移动事件的情况下，异处松开不点击、原处松开只点击一次，不借用缓存悬停。
- 触控回调执行期间也不改写鼠标坐标和窗口内标记；物理鼠标与触点 ID、捕获、按键状态独立。
- 触控关闭鼠标悬停高亮，静止鼠标轮询不重新启用；真实鼠标移动可恢复。按钮只高亮本次按住的原目标，移到别的按钮不高亮，异处松开不触发。
- 关卡共用一个触控植物／铲子／工具选择；多根手指不会持有多张卡。轻点、越界或阳光不足的拖放保留选择，可以再点地种植；选铲子归还植物卡，选植物替换铲子。
- 鼠标仍可独立持卡；种植只提交一次，并重新核对阳光。取消不种植；暂停结束拖动；保存清空触控选择、归还卡片，真实 DAT64 保存／读取与回调内保存通过。
- 掉落卡片失效、传送带槽位重排、侧键模拟、锤子创建／释放／复用通过。
- 真实 `SeedChooserScreen` 在 800、1400 宽度下，鼠标停在别处时触控 Menu 仍创建真实选项对话框；物理鼠标点击同样通过。按住“查看草坪”拖到 Menu 松开，两者均不触发。选卡 Menu 使用窗口坐标，命中函数显式转换事件所属控件的坐标系。

`native-tests.log` 记录主机上的事件合并器、纳秒存档计数和 v4 存档 schema 测试，三项通过。

同源 ARM64 原生事件合并器测试还在 nubia Z60 Ultra（Android 14）上通过。设备执行命令和实际输出保存在 manifest：稳定 ID／pointer index 重排、事件先后顺序、单指／全部取消、十指上限、十万次 MOVE 合并为十次回调、合并器自身零内存分配。这里没有将主机测试冒充 Android UI 实机验收。

## 产物与边界

`manifest.json` 记录源码、Windows Preview、夹具、APK、Android 原生库和 PAK 的 SHA256。已核对 APK 内 PAK、SPIR-V 与同一 Android 构建树一致，APK 原生库与该树经过 Gradle 去调试符号的副本一致；16KB zipalign 和 APK v2／v3 签名验证通过。

手机曾安装并启动“用户列表／独立坐标”阶段的包。最新“共享选中状态／按钮捕获／选卡 Menu”包已构建签名并安装启动，安装前后 12 个 DAT64 文件哈希一致；人工触屏验收仍待用户试用。

Windows 原生触屏与横板 UI 未接入。十个捕获槽不代表每种旧控件内部都支持同控件多指拖动；关卡按用户规则仅有一个共享触控选择。这些是功能回归，不是整局 FPS、功耗或性能提升倍率的测量。
