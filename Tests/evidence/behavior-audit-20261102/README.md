# 玩法核对索引

本索引把九份实际生产对象回归报告按现行枚举交叉核对。53种植物、34种僵尸和72个有效GameMode槽位均有主要工作流检查，模式中含Intro演示及花园；CUSTOM_LEVEL是保留编号，没有原版可玩入口，不计作测试关卡。每项覆盖100／30／240Hz和不规则步长。

植物、僵尸、20个成就小游戏、20个解谜、15个生存、50关冒险首周目／重玩、13个隐藏模式、花园／智慧树／Intro分别保留自己的真实输入、控制条件和原始输出。UI报告另含1200个图鉴页面、620种对象出生、400条奖励路由、224条失败路由、720项开场和16项僵王死亡／花园售花检查。

运行九份报告的capture.py后，再运行本目录capture.py。它要求所有报告来自同一个测试exe和PAK，逐个校验当前源码哈希，验证枚举无遗漏，生成report.json。归档的是有边界的功能证据；不是所有状态组合、完整玩家通关、其他平台验收或性能数据。

仍未复现的“三叶草吹走气球后金币都在最后一行出现”保持为未确认问题。现有泳池六行真实掉落检查正常，不能据此宣称用户现场已修复。其他未覆盖组合在各报告的limits／limitations及README中列出。
