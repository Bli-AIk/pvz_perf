# 花园、智慧树与 Intro 实际入口核对

此报告只覆盖所列真实动作与生命周期，不把初始化／定向场景写成所有经济、日历和交互组合验收。入口使用当前 Release/LTO 对象和实际 PAK，用户资料写入 Temp 私有目录，不覆盖玩家存档。

## 花园：四种步长

每种均运行100／30／240Hz及不规则步长：

- 真实浇水工具动画只影响目标；相邻两株通过实际金水壶范围检查后都被浇水。
- 三次真实施肥动画完成幼苗→小株→中株→成株，每次只扣一个库存。
- 实际杀虫剂、唱片机满足对应需求，库存语义正确；巧克力记录墙钟喂食时间。
- MovePlant 保留盆栽记录和格桶；推车通过实际工具输入取走植株，未把轮式库存误作场内植物。
- 主花园→蘑菇园→水族馆→主花园，环境筛选正确；非水生推车植物不能放进水族馆；放回主花园后位置与记录一致。
- 真实 SaveDetails／LoadDetails 保留成长、园区和位置。蜗牛回到主花园时保留已存位置；另由实际 actor 套件检查新 Board 重进与异常位置恢复。

植物需求和购买状态直接构造，普通移动直接调用 MovePlant；没有覆盖卖花确认、所有手套输入、日历跨日及全部商店购买。金水壶初版夹具把两株放得相距164像素，超出其160像素范围；已改为相邻格，生产逻辑未因此修改。

## 智慧树：五种高度 × 四种步长

高度0、1、12、50、99入场即处于已长成姿态，过场不凭空增长；真实树肥输入播放动画后才增长一次，只扣一份。多更新三秒不重复增长或扣费，99→100触发对应成就；暂停保持 Board 时钟。

## Intro：四种步长

通过 LawnApp::PreNewGame 创建实际展示战场，测试开场预演、暂停、两个一次性音效请求及13.89秒后的实际应用跳转到冒险第一关。音效使用测试管理器计数，不替代扬声器听音。

修复前的真实入口输出保存在 before-intro.txt：100Hz预演一秒；30Hz预演3.3333333秒；240Hz预演0.4166666秒；不规则场景触发时所用步长使预演约1.8765433秒。原因是 LoadIntroBoard 固定嵌套100次 Board::Update，却沿用当前实际步长。

1073发行EXE在0x4445DC调用0x440DC0，后者0x441A49设置100次、0x441A58调用 Board 虚拟更新、0x441A5A递减循环；原固定频率下这是一次初始化预演。现在活跃的 Intro 路径按一秒预算模拟，最后一步取剩余纳秒，恢复调用者步长、旧兼容相位及预演标志。没有推进／倒退全局 Visual 时钟，没有改存档字段。其他已无调用的旧促销预置函数本次未改。

extract.py 校验1073哈希并生成 retail-disassembly.txt。capture.py 要求完整图像套件通过后才归档4项花园、20项智慧树和4项Intro，记录源码、测试exe和PAK哈希；不产生性能结论。
