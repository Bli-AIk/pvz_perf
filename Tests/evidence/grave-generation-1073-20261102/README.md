- 原版锤僵尸及冒险2-5在0x422290设置200次更新的开场等待；首波后在0x428B89设置2000次更新的周期；0x428B3D在剩100次更新时补max(1,5-现有数量)座。对应原版频率下，战斗约21秒首次造墓，之后每20秒一次。
- 新墓另有0..49次更新的随机延迟及100次更新的升起过程，约为0..0.49秒和1秒。当前纳秒表达保留这些素材标度，没有恢复固定频率子循环。
