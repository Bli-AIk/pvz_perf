`HiddenRulesRuntime` 对GameMode 21..33逐项执行100、30、240Hz和不规则纳秒步长，共52个真实Board场景。每项核对背景、波数、初始阳光，以及普通暂停不推进Board时间。本次未因此修改生产代码或存档格式。

## 原版核对与测试预期纠正

- 铲子关用坚果铺场，传送带补给的是**豌豆射手**。1073的`0x456CF0`识别原模式46，`0x425B0F`将种子零／权重100写进唯一候选槽。最初测试误以为给坚果，已修正测试；生产表原本正确。
- 1073暴风雨在`0x42618D`检查暂停计数1、150，再在`0x4261AF`递减。可变步长跨过阈值后，需要下一次更新开始时才能停住。测试原先只运行一次20ms更新，在30Hz／抖动场景观察得太早；现在允许到下一次调用再检查，没有为此改变生产语义。
- Ice的1073原条件是原模式42且主计数恰为3000。现代使用前一时刻／当前时刻跨越30秒，测试故意用3ns跨界，验证没有依赖整毫秒或固定更新数。声音管理器只在测试代码中记录播放请求，没有创建真实播放设备；这不是扬声器听音验收。

`extract.py`校验发行EXE的SHA256后生成`retail-disassembly.txt`，不运行或修改原版。其余模式这里验证的是所列现代运行路径，不声称原版每个隐藏原型都能完整通关。

部分计时缩短、波号和生产期限直接构造，高重力子弹直接调用实际运动入口；艺术图形通过AddPlant完成，松鼠通过真实铲子操作清场。没有统计随机分布、走完全部波次、覆盖隐藏模式所有战术或绘制像素。展示关卡、禅境花园和智慧树另行核对。

入口：`tools/test-image-runtime.ps1 -BuildDirectory out/x64-win32-vulkan -Case hidden-rules -OutputDirectory $env:TEMP/pvz-hidden-rules-runtime`。`capture.py <log> <test-exe> <pak>`要求完整图像套件也通过，检查52个唯一组合，再保存输出及源码／exe／PAK哈希。所有临时写档使用Temp私有目录，不覆盖玩家存档，不产生性能结论。
