# 植物主要行为逐株核对

当前覆盖 `NUM_SEED_TYPES` 内全部53种植物，每种分别运行100、30、240Hz和不规则纳秒步长，共212个场景。`ImageRuntimeTests.cpp` 检查两组名单恰好覆盖每个真实SeedType一次，未把种子栏按钮等非植物枚举计入分母。

- 23种射手／生产植物：经历真实定时触发、射击动画、出弹和命中流程，核对单次攻击弹数、弹种、范围伤害次数，以及阳光／金币产量。不是直接调用Fire后数产物。
- 30种特殊／辅助植物：核对爆炸及消耗、土豆雷出土与引爆、大嘴花吞咽与消化、墓碑移除、魅惑、寒冰冻结、海草下潜、咖啡唤醒、蒜换行、保护伞恢复、玉米炮装填／开火、模仿者与格桶更新、防御植物生命与咀嚼伤害、底座无敌期、地刺伤害、火炬解冻／点燃、路灯粒子、三叶草吹走、磁铁夺盔／收币、爆炸与巨型保龄球，以及真实花园幼苗的动画存续。

该结论只覆盖各类型的主要场景，不代表所有交互、地形、保存恢复和状态分支都已验收。保护伞从实际DoSpecial入口触发；金磁铁从实际吸取动画开始，绕过随机等候；幼苗检查花园归属与稳定播放，生长／喂养仍需另外核对。目标使用真实但静止、高生命的僵尸以隔离植物动作，不能据此给所有僵尸的运动背书。三叶草金币集中最后一行的用户现场仍未复现。

运行完整套件：`tools/test-image-runtime.ps1 -BuildDirectory out/x64-win32-vulkan -OutputDirectory $env:TEMP/pvz-plant-catalog-runtime`。

只运行这批植物场景可增加 `-Case plant-attacks`；它仍加载生产资源、定义和真实游戏对象，并非替身逻辑。完整套件通过后，使用 `capture.py <log> <test-exe> <main.pak64>` 保存原始输出、212条结果及源码／二进制哈希。此处不包含任何新的性能结论，不表示整个夜间逐项审计已完成。
