`PuzzleRulesRuntime` 对GameMode 36..55各运行100、30、240Hz及不规则纳秒步长，共80个真实Board场景。本次这些场景没有发现新的生产代码缺陷；以下是已检查范围，不声称自动打通全部随机局面。

| 我是僵尸1..9／无尽 | 初始150阳光、各关卡槽数、五个70口脑子、合法布阵范围、纸板植物停播／土豆雷已布防；普通／蹦极放置方向；场上有可拾阳光时不误判失败 |

额外明确构造两种无尽的零基轮次0、1、2、8、9、10、19、79、80，共18个布局／结算边界。验证我是僵尸每完成3轮奖励、砸罐每完成10轮奖励，以及无尽砸罐巨人数`1+min(stage/10,8)`和我是僵尸前两轮的小喷菇数。奖励检查调用实际`PuzzlePhaseComplete`，没有把直接构造的第80轮写成连续打过80轮。

原版1073的`0x42C4D0`函数对已完成轮次执行INC、CDQ、IDIV，检查3或10的余数；`0x42C520`结算入口重复相同规则。`extract.py`核对发行EXE的SHA256后只读反汇编，输出保存为`retail-disassembly.txt`。

测试先打开非僵尸罐、再逐个检查僵尸罐；为隔离内容，检查后的敌人直接死亡，只保留最后一只验证结束门槛。射手目标临时高生命／静止，部分等待缩短。测试不是随机战术求解器，不覆盖每种布阵、多罐同时开、窝瓜／魅惑等全部配合。真实回调可能写成绩；测试主入口将用户目录固定到Temp输出目录下的`fixture-user-data/<PID>`，不读取或覆盖玩家存档。

定向入口：`tools/test-image-runtime.ps1 -BuildDirectory out/x64-win32-vulkan -Case puzzle-rules -OutputDirectory $env:TEMP/pvz-puzzle-rules-runtime`。`capture.py <log> <test-exe> <pak>`要求完整图像套件也通过，再核对80个唯一组合、40项防守动作、40组脑子／罐子和18个边界，保存原始输出及源码、exe、PAK哈希。

冒险、生存、隐藏关、花园与智慧树仍需单独验证。本证据不产生性能结论。
