# 场上卡牌触控修复验证

日期：2026-11-03。夹具链接当前 Windows Vulkan Release 的实际生产对象并读取同批 PAK。测试不调用用户游戏窗口，不读取用户真实存档。原始输出为 touch-input.log；源文件及产物 SHA256 记录于 manifest.json。

测试分别使用真实的种子雨与砸罐子模式，在原有 Board 输入夹具上完成：

- 新卡轻点并带 4 像素抖动，不原地种植；再点同卡只归还一次。
- 点另一张直接换卡，旧卡恢复可用；拖回来源卡或仍在来源范围内松手保留选择。
- 拖动经过另一张卡不换来源；第二根手指不能另拿一张；最后只种植捕获 CoinID 对应的植物并消费一张卡。
- 无效区域松手保留卡，随后点地种植；卡槽、场上卡和铲子相互切换。
- 鼠标拿着的场上卡不会被触控抢走，也不会导致触控误种；鼠标坐标保持不变。
- 相同位置的卡按渲染顺序选顶层，顶层再点可取消。
- 800／1400 逻辑宽度加平移的场上卡蓝框，与独立像素裁切参考逐像素一致；实际 GPU 读回为 touch-field-card-*.png。
- 来源 Coin 被删除并重用槽位后，旧 CoinID 不会操作新对象；持有来源卡时实际 DAT64 保存／重载，瞬态选择不进入存档。
- 砸罐子在手指按住期间运行真实 anim_open_pot 锤子，产出指定寒冰射手卡；同次移动／抬指既不拿新卡，也不种旧卡，下一次新手势才能选择新卡。

原有用户列表、按钮捕获、共享种植、目标高亮、卡槽／铲子框、白带、双炮、扫取奖励、实际保存和 800／1400 选卡 Menu 回归也通过。四项基础 CTest 输出见 native-tests.log。

生产代码仅改 BoardTouch.cpp／BoardTouch.h，没有修改平台输入、鼠标规则或存档结构，DAT64 仍为 v4。此记录不包含正式性能倍率；手机安装与人工手感验收另行记录。
