# 花园工具与触控绘制回归

使用当前 Vulkan Release 的实际生产对象、真实资源包和 GPU 像素读回。测试入口为 `tools/test-image-runtime.ps1 -Case touch-input`。没有操作真人游戏或玩家存档。

- 八种花园工具分别轻点选择、再次轻点取消、从其他工具直接切换；选择过程不扣库存、不生成喂养动画。
- 两个触点同时按不同工具，只有共享选择的主触点生效；真实鼠标位置和鼠标光标保持独立。
- 手套拿起真实盆栽后取消；装入手推车；用手套取出后取消，手推车内容保持完整。
- 智慧树肥料选择／取消。
- 水壶、手套、手推车在 800／1400 宽度、非零 Board 偏移下，生产四角框与独立像素裁切参考全图一致。
- 同一回归还包含铲子和植物的白色加法宽带、屋顶斜面、空地隐藏、场上卡牌、罐子、炮手势、扫取奖励和选卡 Menu。

结果见 `runtime.log`、`native-tests.log` 和 `manifest.json`。`touch-garden-frame-*.png` 是 GPU 读回的实际选中框。修改没有增加存档或触点状态字段，DAT64 保持 v4。安卓 APK 在同一 Android 构建树打包并校验 SO、PAK 和所有 shader；已安装到 FY241471004E（NX769J），冷启动成功、进程保持运行。安装前后外部用户目录的 18 个文件哈希一致；尚未作真人花园交互验收。
