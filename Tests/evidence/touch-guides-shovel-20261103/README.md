# 铲子、加亮条带与屋顶斜面验证

日期：2026-11-03。Windows Vulkan Release 的实际生产对象和匹配 PAK 已构建并运行 touch-input；结果为 touch-input.log。手机安装与人工手感另记。源文件、可执行文件和 GPU 读回证据的 SHA256 见 manifest.json。

## 参考实现

- Free 3.18.0：DrawCelHighlight 使用 Color(0xffffff,64)、drawMode=1（加法）。Color 双整数构造的指令确认 RGB 与 Alpha 分别写入，未把 64 误读为其他参数。
- Free 的 DrawGroundLayer 先绘制目标行，再绘制目标列除去目标格，最后对目标格 force=true 绘制一次；单触点目标格比其余条带多加亮一层。
- Free 屋顶用当前列与下一列的 GridToPixelY+20 构造四边形，非末行的底边使用下一行高度，末行高度80。相邻列共用边，行带沿坡面连续。
- WP 固定参考提交：RGB=(50,50,50)、Alpha=0，Graphics 的预乘 AlphaBlend 入口保留颜色来加亮；不等于普通透明覆盖。屋顶每列以矩形画格，行带是台阶。此处针对参考工程，未逐指令复核原发行 WP DLL。

来源 URL、文件哈希与 Free 原生库身份在 reference-sources.json；三份 Free 指令文件单独保留。没有根据图片名字猜测颜色，也没有引用改版的示意图作为原版行为。

## 当前实现与实际检查

条带改为 Free 的纯白 Alpha64 加法；平地／泳池为两个矩形，屋顶为沿坡的凸四边形。铲子指向可铲植物时加入同样的行列提示，指向空地不显示。几何通过凸多边形的现有 GPU 入口提交，不进入 PolyFill 的 CPU 扫描线路径，也不使用纹理。

夹具分别在平地、泳池、屋顶建立植物和铲子手势：

- 实际 GPU 读回核对黑底普通条带每通道约64、目标交点约128；容差一个颜色级。
- 彩色底图(24,48,72)的目标点输出约(152,176,200)，区分加法混合与普通 Alpha 覆盖。
- 屋顶斜边两侧像素和相邻列接缝通过，排除旧矩形台阶形状。
- 铲子移到空格后图像回到黑底；触点取消后条带也完全消失。
- 其余触控捕获、用户列表、蓝框、目标高亮、掉落卡牌、真实砸罐子产物、双炮、扫取奖励、DAT64与选卡 Menu 回归均通过。

六张 touch-guides-*-plant/shovel.png 是隔离植物幻影后的真实 GPU 读回，目的是检查几何和强度，不是游戏场景截图。没有记录整局性能结论，也未据此宣称与 Free 全部地形布局逐像素一致。

本轮没有增加持久字段或触控状态字段，存档仍为 DAT64 v4。生产改动只有 BoardTouch.cpp。
