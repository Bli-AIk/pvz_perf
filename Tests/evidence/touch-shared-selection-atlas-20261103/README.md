# 共享选择与 FixedUI 四角框

Windows Vulkan Release 生产构建与实际 PAK 通过触控专项回归。鼠标与触控换卡、来源归还、取消和保存流程使用单一选择所有权；坐标与炮拖动上下文仍独立。鼠标待发炮准心在战场收到触控时取消，触控可从炮身开始新的拖动。卡槽／场上卡选中不再因持有状态整体变暗，正常冷却与消失闪烁保留。

四角框合入 FixedUI 图集，四个区域由资源编译器输出。没有运行时独立 Image 全局符号或独立资源包图片。原 PNG 仍作为源资源和独立测试参考；测试显式加载图集，原图应用同样的加载期透明边缘处理。800／1400宽度的卡槽、铲子、场上卡及花园工具像素对照，观察到最大通道差为0。

图集工具13项测试、实际输入／GPU读回和四项原生检查通过，见日志及 manifest.json。没有新增存档字段；手机包本轮未更新。无尽性能数据对应这些后续改动之前的程序，另见 windows-vulkan-lp14-240-touch-20261103。
