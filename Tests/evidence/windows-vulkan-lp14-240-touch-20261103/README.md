# LP14 / 11x / 240FPS 触控接入后观察

本轮在 Release 目录运行，按 Enter 启动、Quit 结束。原版无尽起点经当前转换器转为 DAT64 v4，入场状态见 checkpoint.json，版本、配置及文件哈希见 conditions.json。11x 由用户设置，未独立采集频率。

有效战斗369秒，平均182.710FPS，单核口径CPU 92.471%，5.06109 CPU ms/绘制帧。曲线只绘制 game 区间，CPU时间来自进程累计user+kernel时间，不是逐帧CPU延迟。用户确认本轮战斗中既短按过侧键，也按住并拖动过；没有逐事件日志，无法从现有采样恢复具体起止时刻。

此前196.736FPS／4.552ms记录来自2026-11-01的3.2.4运行路径，不是v3.2.5对照包。前10波两轮分别170／168秒，第10至19波132／148秒；整局有效时间359／369秒，不支持单纯以整局加速解释下降。波次相同也不证明瞬间存活对象、手动操作和攻击轨迹相同。

## 相对 v3.2.5 的源码审计

对照tag v3.2.5（21c5ff4）。本轮采集后的共享选择、去除选中变暗、取消鼠标炮目标和蓝框进图集改动均不属于被测EXE。

- 植物、僵尸、Challenge、Reanimator、TodParticle和主循环实现未相对该tag改变。没有新增出怪倍率、关卡时钟加速或逻辑补拍。
- Board增加触控光标更新、触控高亮和预览绘制入口。无上下文／无活动触点时提前返回；活动触点则增加一次预览、光标与命中计算。
- 按住Windows侧键并移动鼠标，原鼠标路径继续执行，同时产生触控MOVE；每次模拟MOVE扫描钱币并作线段命中，且调用原MouseDrag。Windows的模拟MOVE来自每拍的NativeMouseMove采样，不是每条OS鼠标消息；不能把这部分成本直接乘以鼠标回报率。Android另有连续MOVE合并。用户本轮使用了侧键，因此不能按“无触控开销”解释这一轮。
- 选中框额外提交四个角；种植／铲子拖动另有行列宽带和目标高亮。它们取决于实际操作，并非整局恒定成本。
- GameButton改为事件坐标命中；Update中计算父控件绝对位置，鼠标／触控捕获处理增加固定十槽查询。无触点时跳过触控槽扫描，未引入每帧全池僵尸或粒子扫描。
- 图鉴、用户列表、头像编辑、通关页以及Android平台适配，不作为本轮Windows战斗热路径成本。

静态审计确认新增工作位置，不能由此量化0.509ms/绘制帧的归因。严谨的下一次比较应使用v3.2.5与当前版本、同一冻结场景，并分别测试无侧键与侧键拖动；本次完整战斗数据继续保留，不回写为单项优化收益。

后续已删除侧键模拟，Win7／Win10分别接入原生触控；不修改本轮被测程序或采样结果。
