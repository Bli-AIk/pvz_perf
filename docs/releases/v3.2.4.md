# v3.2.4

本次发布三个平台：

- `x64-win10-vulkan1.3-v3.2.4.zip`：Windows 10 x64，Vulkan 1.3及本项目所需descriptor indexing能力。
- `x64-win7-openGL3.3-v3.2.4.zip`：Windows 7 x64，厂商OpenGL 3.3驱动。
- `arm64-android14-vulkan1.3-v3.2.4.apk`：ARMv9-A、Vulkan 1.3，Android 14实机测试路径；不包含旧ARM／旧Vulkan回退实现。APK内置资源包、完美进度与泳池无尽基准，无需手动另拷数据包。

另外提供独立完美存档、无尽基准及二者合集。Windows包内也包含生成的PerfTest资料与基准，不包含个人游玩存档或个人设置。

## 改动

- Android使用原版程序ICO生成的五档应用图标。
- reanim的两个倾斜轴各调用一次FastSinCos，共享角度范围归一化，四角复用变换矩阵。相位、根运动与存档布局不变。
- 普通贴图矩形直接构造最终四角顶点，减少中间转换、重复颜色归一化和六顶点展开。
- Vulkan每帧槽固定65536个顶点，无分页、选页或扩容机制；超限明确报错，容量包含最终呈现几何。两套动态几何及索引流合计5.375MiB，不复制素材纹理。
- 更新现行微基准与按原理组织的性能文档；保留仍有意义的1.0对照和退役路径的边界说明。

reanim与particle继续在CPU求值，GPU消费最终几何；不重新启用已撤销的GPU动画求值、公式粒子或主线程流水线试验。

## 存档与资源

本次没有新增存档格式变化，关卡仍只读取DAT64 v4（schema `0x10745`），与v3.2.3的v4档一致。v1.x／v2.x的关卡档须先转换，全部未发布v3中间格式不受支持；用户资料格式维持现状。

资源包与程序必须整套更新。不要将新程序与旧main.pak64混用，也不要把旧版本资源包覆盖进本包。

## 验证与测量

- 三平台Release构建；Windows启用LTO，Android启用full LTO。
- Vulkan原生像素、同步、资源生命周期及65536顶点边界检查通过；视口检查通过。
- Win7构建使用匹配的MSVC 14.44头文件／库，已检查已知Win8+硬导入。
- 当前生产查询、真实对象结构、帧缓存、粒子侧表、FastMath、固定DX12绘制、13项段表及17项粒子身份模型均完成串行复测。完整边界见[性能文档](../perf-fix-ledger.md)。
- 同运行路径的Vulkan泳池无尽：LP14、用户11x、240Hz上限，平均196.74绘制FPS、89.55%单核口径CPU、4.552 CPU ms/绘制帧。该值为一次完整场景观测，包含更新及其他线程工作，不是单项优化倍率或逐帧p99。

测量证据：[当前微基准](../../Tests/evidence/v324-microbenchmarks-20261101/README.md)、[完整无尽汇总](../../Tests/evidence/windows-vulkan-lp14-240-20261101/summary.json)。
