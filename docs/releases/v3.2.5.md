# v3.2.5

本次发布三个平台：

- `x64-win10-vulkan1.3-v3.2.5.zip`：Windows 10 x64，Vulkan 1.3及本项目所需descriptor indexing能力。
- `x64-win7-openGL3.3-v3.2.5.zip`：Windows 7 x64，厂商OpenGL 3.3驱动。
- `arm64-android14-vulkan1.3-v3.2.5.apk`：ARMv9-A、Vulkan 1.3，Android 14实机测试路径；不包含旧ARM／旧Vulkan回退实现。APK内置资源包、完美进度与泳池无尽基准，无需另拷数据包。

另外提供独立完美存档、无尽基准及二者合集。Windows包内包含生成的PerfTest资料与统一基准，不包含个人游玩存档或个人设置。Android覆盖安装保留已有用户数据；内置基准不自动覆盖正在游玩的进度。

## 行为与界面修复

- 修正双发、反向双发和裂荚提前触发的时间起点，避免第一发被后续触发覆盖。
- 开场预置墓碑直接完整显示，便于选卡时观察场地；保留随机数消耗。战斗中新生成的墓碑仍使用延迟与升起动画。
- 暂停框报纸僵尸由控件显式传入墙钟时间，关卡暂停时继续播放。
- 修正Zombie Nimble Zombie Quick第二次更新的时间推进，植物、僵尸和攻击正常加速，水面与独立特效保持原速度。
- 修正Zombiquarium左右键路由、脑子食物年龄判定，以及Beghouled Twist、老虎机宽屏坐标。
- 图鉴与商店放行UI时钟而保持战场暂停；植物、僵尸创建时立即绑定管理者时钟，避免首步动画年龄丢失。
- 修正传送后直线运动基准、僵尸停走／定身恢复时的运动段，以及投篮弹药按时间而非次数扣减的问题。
- 图集上传纳入公共透明边缘修补，改善噬碑藤等线性采样白边；不增加逐帧处理。
- Intro初始化预演按实际步长完成一秒，避免高低目标帧率改变预演时长。
- Challenge按模式使用静态函数表，保留各处理阶段顺序及冒险特殊关卡路由。

本次不改变reanim／particle的CPU求值与GPU绘制分工，不重新启用GPU动画、公式粒子或线程流水线试验。新增动画网页用于说明机制与已有测量，视频配音仍在试听阶段。

## 存档与资源

没有新增存档格式变化，关卡继续只读取DAT64 v4（schema `0x10745`），与v3.2.4保持一致。v1.x／v2.x关卡档须先转换，未发布v3中间格式不受支持；用户资料格式不变。

程序与main.pak64必须整套更新，不混用旧版本的程序、资源包或定义文件。

## 验证边界

Windows Vulkan／OpenGL和Android使用各自Release构建；Windows LTO，Android Full LTO。发布前执行当前生产对象的图像、资源、玩法及时间／存档回归；具体场景和构造条件见[验证说明](../validation.md)与[玩法核对索引](../../Tests/evidence/behavior-audit-20261102/README.md)。

这些检查覆盖主要工作流，不代表所有随机交互、保存中断点、平台驱动或关卡均已完整实玩通关。三叶草吹走气球后金币集中在最后一行的用户现场仍未复现，不将其列为已修复。本次未重新登记整局性能提升；已有结果保留原版本、频率及测量范围。
