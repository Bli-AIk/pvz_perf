# v3.3.1

提供三个完整程序包：`x64-win10-vulkan1.3`、`x64-win7-openGL3.3`、`arm64-android14-vulkan1.3`。Android 7／Vulkan 1.0 兼容路径保留在源码中，本次不附第四个安装包。

## 横板 UI

- `settings.json` 的 `landscapeUI` 控制布局，启动时确定；不随鼠标／触控输入切换。Android 有效视口比例不足 890:600 时静默使用桌面布局。
- 采用四列选卡列表、左侧紧密卡槽、原生尺寸阳光栏／铲子及传送带。卡牌价格位于卡面内部，冷却遮罩从左侧先褪去，场上掉落卡片仍保留竖版。
- 鼠标滚轮、触控拖动及惯性滚动覆盖选卡、模仿者和成就页；退出菜单、图鉴、商店或模仿者后恢复选卡焦点。
- 横板 HUD 高于战场与雾，低于阳光／金币；黄色四角框避开价格。铲子使用目标高亮，种植条带仅在目标合法时显示。
- 优先向左／右扩展只应用于关卡，其他页面两侧均分；修正横板阳光收集目标与震动画面偏移。桌面布局优先右扩，横板布局优先左扩，继续扩展时遵守背景左右各自边界。

## 资源与平台

- UI 分为 `common_ui`、`desktop_ui`、`landscape_ui` 三张独立图集。共用对话框、按钮和蓝色选框始终加载，桌面／横板专用纹理在加载期二选一；资源包保留两种布局以便修改设置后重启。
- 桌面选卡背景、模仿者扩展底板和剪影改为直接使用图集 UV，删除对应三个普通全局图片绑定。图片原尺寸、透明度和采样方式保持原定义，不增加逐帧资源查找。
- 项目自己创建的运行线程启用非正规浮点数归零处理；不以此宣称已经证明整局性能提升，也不宣称覆盖第三方音频库内部所有线程。
- Android 修复旋转声明与正向绘制不一致的问题；Quit 完成原生清理后终止 Activity 的应用进程，不因切后台或配置变更强行退出。
- Android HDR 仍禁用，配置为 true 时归一化为 false。FP16／scRGB 试验保留为默认关闭的编译选项；手机发灰和玄戒 O1 平板过曝尚未通过校准，不作为正式 HDR 支持发布。
- APK 包含同树 SO、pak64、shaders、BASS，以及生成的完美档与原版转换的泳池无尽基准；无需另拷数据包。

## 格式与迁移

存档仍为 DAT64 v4（schema 0x10745），玩家详情为 PVZUSR64 v13，本次不修改存档格式。可沿用 v3.3 存档。原版 DAT、DAT64 v1／v2 使用附带转换器；未发布的 v3 中间格式不支持。

EXE／SO、shader 和 `main.pak64` 必须使用同一发行包，禁止跨版本混配。仍沿用 v3.0 对 v1.x／v2.x 的破坏性资源／存档边界。完美档是生成的 PerfTest 用户，不包含私人进度；测量前请重新导入无尽基准。

本版不将此前 HDR 或插桩条件不同的测量写成新的性能收益。源码附带图集求解缓存；60 秒限时后的合法布局保留实际 FEASIBLE／UNKNOWN 状态和 gap，不冒称全部已证明最优。
