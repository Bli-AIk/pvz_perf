## 网页包

网页包包含 WebGPU 和 WebGL 2 两个平级后端，默认优先 WebGPU，不可用时使用 WebGL 2，也可在启动页手动选择。两后端共用同一份资源和浏览器存档，只加载所选运行时。WebGPU 使用参照 Vulkan 1.3 整理的采样、过滤与混合 shader，保留两套动态帧资源和可选双源混合；不宣称未经手机实测的性能收益。

GitHub 包绕过 B 站接口，可以本地运行。解压后运行 `start-local.cmd` 或 `start-local.sh`，再在浏览器打开本机地址；不能直接以 `file://` 打开。WebGPU 需要安全上下文（HTTPS／localhost）。

B 站包仅在点击“领取完美存档”和“自定义无尽”时检查是否给 `BV1hV4P6PEDc` 投满两个币，或是否为作者本人；视频按钮优先使用 Toy SDK 的视频跳转。GitHub 包不要求登录或投币。

网页进度存于当前网站来源的 IndexedDB，虚拟路径 `/persist/development-v331/`。切换后端保留存档，不同浏览器／来源不共用。清除网站数据会删除进度；自定义无尽支持 DAT64 导出。包内清单记录源码提交和文件校验值。

网页附件补充修复：手机触控不再依赖 SDL 键盘焦点，点击画布可在宿主未响应焦点请求时恢复游戏输入。手机 UA 默认目标为 60 FPS，并标注为建议值；手机 B 站环境不检测刷新率、不自动跟随，仍可手动调整目标帧率。WebGL 和 WebGPU 均已通过模拟失焦恢复测试，B 站手机实机行为仍待验证。

本次只替换网页附件及校验记录，四个原生包与 v3.3.3 标签保持不变。网页补充源码以 ZIP 内 `web-build-manifest.json` 的 `source_commit` 为准。

版本号规则：第一个数表示破坏性更新，第二个数表示功能更新，第三个数表示 bug 修复。
