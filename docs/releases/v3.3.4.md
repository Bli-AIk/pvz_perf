# v3.3.4

本次提供四个原生包和网页版。网页附件为后续补充发布，原有四个原生附件与 v3.3.4 标签保持不变。

## 修复

- 桌面与横板 UI 的传送带选中框遵守传送带范围，不再越过边缘。
- Credits 取消固定 800×600 的外层裁剪，保留分镜合成所需的局部遮罩；背景偏移不变，结尾黑色遮罩覆盖整个窗口。
- 修复给蜗牛喂巧克力后，在转身动画中错误计算移动根轨道而崩溃的问题。仅爬行状态计算水平位移，沿用原有状态判断。
- 所有图集装箱的宽、高上限均设为 4096。超过上限的字体长条在字形边界折行，保持字形像素、字宽、字距和偏移，不在运行时缩图；对应布局缓存同步提供。
- 超出设备纹理上限时，错误提示包含实际尺寸与设备上限，不再固定写成 Vulkan 设备错误。

## 下载与兼容性

- `x64-win10-vulkan1.3-v3.3.4.zip`
- `x64-win7-openGL3.3-v3.3.4.zip`
- `arm64-android14-vulkan1.3-v3.3.4.apk`
- `arm64-android7-vulkan1.0-v3.3.4.apk`
- `wasm32-web-v3.3.4.zip`

更新时同时更换程序与 `main.pak64`，不要混用旧资源包。存档格式仍为 DAT64 v4／schema `0x10745`，与上一版本兼容；v1.x／v2.x 程序及资源包不兼容本版本，旧关卡档请先使用附带转换器转换。

完美存档已购买坚果包扎术，无尽基准由原版基准重新转换。桌面版存档位于程序目录的 `data` 子文件夹，Android 存档位于 `Android/media/com.openpvz.perf`。安装 Android 包会在首次启动时准备附带的完美存档及无尽基准，保留已有用户资料。

版本号规则：第一个数表示破坏性更新，第二个数表示功能更新，第三个数表示 bug 修复。

## 网页版

- WebGPU 与 WebGL 2 两个后端共用资源、设置及本地存档；启动前检测能力，不显示不可用后端。仍不适配 WebGL 1。
- 所有图片宽、高不超过 4096；OGG 使用随 Wasm 编译的解码器，补充初始化超时、图形上下文丢失等错误反馈。
- 同一页面会话中重复开始与 Quit 复用运行时，不重复准备资源和存档。正常退出后同步浏览器数据库；失败时保留内存数据，并显示“重试本地保存”。
- 用户进度支持本地独立备份；B 站配置还可通过 Toy 云存储备份用户资料。关卡 DAT64 始终只在本地，由用户自行导入／导出备份。
- “自定义存档”以用户进度为首页，支持用户增删、改 ID／名称、编辑进度；ID 修改迁移所属关卡文件。移除领取完美存档入口，保留未编辑的花园与大头贴数据。
- 布阵器支持六场景、阵型删除、无尽旗数／种子／阳光、自定义关卡文件名及模式对照。冒险另设 1～50 的关卡，并同步目标用户进度；隐藏关及四种隐藏无尽归入 limbo 折叠区。
- “开始游戏”“上传云端”“从云端恢复”位于顶部，上传时红字提醒；图形接口、画面比例、显示帧率收进默认折叠的“高级”。

GitHub 网页 ZIP 绕过 B 站接口，不要求登录或投币；云端功能仅用于 B 站宿主配置。B 站配置的自定义存档入口仍检查指定视频投满两个币或作者身份，弹窗内不重复查询。此处没有更新 B 站作品。

完整解压后运行 `start-local.cmd`（Windows，需 Python 3）或 `start-local.sh`，通过 localhost 打开，不要直接以 `file://` 打开。WebGPU 需要 HTTPS 或 localhost；普通 HTTP 局域网通常使用 WebGL 2。存档位于当前来源的浏览器 IndexedDB，清除网站数据会删除本地进度。

网页补充源码以 ZIP 内 `web-build-manifest.json` 的 `source_commit` 和源码链接为准，修改器产物同时附带 PvzDevTools 来源及校验值。存档格式保持 DAT64 v4／USER64 v13，没有新增格式变更；不宣称未经实测的性能提升。
