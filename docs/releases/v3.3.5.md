# v3.3.5

本次发布四个原生包和网页版。存档格式保持 DAT64 v4／schema `0x10745`、USER64 v13，与 v3.3.4 兼容。程序、资源与 shader 应成套更新。

## 游戏修复

- 攻击更新跨过发射时刻和收尾时刻时，不再因提前返回而漏掉收尾处理；覆盖玉米加农炮及投手攻击状态。
- 寒冰菇冻结僵王时保留独立冰球／火球的根运动绑定，冰球继续滚动。每个僵王同时最多持有一个冰球或火球，字段复用及其约束已写入注释。
- 僵尸进家后冻结关卡时钟和其他植物、僵尸，仅进家的僵尸由所有者传入 visual 时间，继续播放进家表演。
- 横板 UI 的卡槽、铲子及右上角 UI 共用 PC 的绘制阶段和队列层级；开场对话阶段，铲子遵守原有升层规则，绘制在戴夫与对话框上方。
- 核对原版 1073 EXE 与资源，确认罕见的超长噎死动画仍有播放分支，保持原有触发条件，不将其误删为废弃彩蛋。

## 网页修复

- 图形能力检测增加实际绘制、混合和纹理采样验证；不提供不可用后端，保留 WebGPU 优先与 WebGL 2 选择。
- 资源完成后还需确认后续更新与绘制正常推进，补充启动阶段、超时和内存信息，避免只留下无提示黑屏。
- 音乐工作线程初始化、命令执行或状态同步失败时保留错误原因，停用 BGM 后允许音效和游戏继续；取消遗留等待，下一次正常开始可重试。
- 页面恢复、再次触摸或按键时恢复被宿主暂停／中断的音频上下文，不增加每帧轮询、不重置音乐进度。
- 设置页改用文档原生纵向滚动，改善部分移动 WebView 中无法下滑的问题。
- 自定义存档使用同源内嵌页面，不再请求可能被 Toy 替换成密码验证页的次级 HTML。
- 删除阵型等确认操作改用页面内对话框，不依赖宿主可能禁止的原生 `confirm()`；确认按钮不依赖沙箱表单提交权限。
- 阵型库使用完整 JSON 快照，保留删除结果及空列表；支持 JSON 导入／导出及独立的 Toy 云端键值备份。关卡 DAT64 仍只在本地保存。
- 增加可选运行诊断，正式包默认关闭。启用后有限保留运行状态，可在异常退出后导出上一段记录；不上传诊断、不包含账号或存档。

## 验证范围与待调查反馈
