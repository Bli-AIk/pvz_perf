# v3.3.6

本版修复植物攻击计时及网页动态音乐，统一 WebGL 检测与实际启动配置。
DAT64 v4／schema `0x10745` 的磁盘格式不变；请成套更新程序和资源。

## 游戏修复

- 植物攻击内部使用外部传入时间与预期结束时刻判断事件，不再逐拍扣减射击倒计时。跨过发射与到期边界时继续执行收尾，等待动画完成期间保留有效期限，避免植物保持末帧后攻击停止。
- 自动发射仍从上一轮预期时刻安排下一轮，保留越过期限的时间，不因清零重置累计延长攻击周期。
- 不在游戏内自动修复旧坏档；已损坏的玉米炮零计时末帧状态使用独立 PvzDevTools 修复工具另存处理。ICE3／ICE4 的僵尸事件顺序保持不变。

## 网页修复与运行时

- 自定义存档的用户进度页新增“新增完美存档用户”：自动分配空闲 ID，填入随包完美档的全部进度与购买状态，保留已有用户和关卡；不必逐项修改。

- Web 音频适配实现 `MUSIC_PSCALER=4`。鼓声进入、退出及暂停恢复使用正确的音乐位置尺度；解码器缓存和跳转位置保持原始行号。原生 BASS 路径不变。
- WebGL 检测与实际启动统一申请 RGBA、无深度、无模板、无多重采样表面，消除两套参数导致的误判。模拟驱动回归通过；OPPO A3x 5G／ColorOS 15／天玑 6300 上的 `EGL_BAD_MATCH` 仍需反馈用户真机确认。
- 同一个 ZIP 包含 wasm32／wasm64 各自的 WebGPU 与 WebGL 2，共四个运行时。默认 wasm32，支持 Memory64 的浏览器可在高级设置手动选择 wasm64；仅下载选中的运行时，资源、设置和存档共用。
- 高级选项可导出诊断记录。持续记录默认关闭；关闭时不运行周期采样或写入诊断存储，仍可按需导出当前环境快照。

## 验证

植物全类型行为、重复冰瓜与玉米炮攻击、攻击期限存读档及 ICE3／ICE4 回归通过。
四种曲目的鼓声控制在 30～1000 FPS 下通过入场、退场和再次触发测试；实际 BASS
与 Web MO3 解码验证通过。四个 Web 运行时通过启动、绘制、正常 Quit、共享设置及
相同 DAT64 解码检查。浏览器模拟验证不替代上述 OPPO 或 iPhone 机型的真机验证。
