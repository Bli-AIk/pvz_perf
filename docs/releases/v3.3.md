# v3.3

本版重点是原生触控与鼠标并用。提供 x64-win10-vulkan1.3、x64-win7-openGL3.3、arm64-android14-vulkan1.3 三个完整程序包，另附生成的完美用户档、统一泳池无尽基准和图集编译缓存。

## 输入与选中状态

- Android 多点触控；Windows 7 使用 WM_TOUCH，Windows 10 使用 Pointer API。鼠标侧键不再模拟触控，合成鼠标消息过滤，真实鼠标可与触控并用。
- 触控坐标直接传给事件和控件，不改写鼠标位置。触控关闭鼠标悬停高亮；按下的按钮离开即熄灭，按下与松开不属于同一个按钮时不触发。
- 鼠标和触控共用唯一的植物／铲子选择。再次点击已选卡牌或工具取消；轻点或拖放失败保留选择，可以再点地种植。玉米加农炮保持多指独立拖动发射，距离不足一格不提交。
- 阳光、金钱和通关奖励经过即拾取，不抢走炮的拖动目标。种子雨／砸罐子场上卡片、花园工具、铲子目标和屋顶辅助条带按各自规则处理。
- 蓝色四角框进入离线图集；卡槽／工具框与底层 UI 一起绘制，场上卡牌框跟随对应卡牌，不再浮在遮挡它的僵尸上方。

## 行为与设置

- 僵尸统一采用动作事件、当前相位准备、根运动求值的处理顺序；保留原版 ICE3／ICE4 的关键帧中断窗口，代码注释说明其含义与移除方法。
- 音乐和音效设置都记录 0～100 的滑条百分比，读取时钳制，保存时四舍五入。音效原有的 0.65 满格增益只在运行时换算。旧设置 sfxVolume=65 在新语义下表示滑条 65%，需要满格时设为 100。
- Windows Vulkan／DX12 HDR 输出统一为线性 RGBA16F，省去生产输出中的 PQ 编码；不据此宣称性能提升。Win7/OpenGL 保持 SDR。Android HDR 未通过显示校准，本次跳过并禁用开关，不发布试验画面。
- Android 首次启动在设置同目录创建空的 scale.json，已有配置不覆盖；不接入运行时 HLSL/compute 超分效果链，加载期超分与缓存尚未实现。
- 临时 CPU／GPU 分相插桩已从生产路径清理；原始测试数据保留，未把插桩测试重标为正式性能结果。

## 格式与安装

存档仍为 DAT64 v4 / schema 0x10745，玩家详情仍为 PVZUSR64 v13，本次不更改存档格式。沿用 v3.0 的迁移边界：原版 DAT、DAT64 v1/v2 使用附带转换器，未发布的 v3 中间格式不受支持。

EXE／SO、shaders 和 main.pak64 必须成套使用，不能仅替换其中一个。Windows 解压到新的可写目录；Android APK 内含数据包，要求 Android 14、ARM64 ARMv9-A（不依赖 SVE）以及 Vulkan 1.3 和所需 descriptor-indexing 能力。

完美档为生成的 PerfTest 用户，不包含个人进度。无尽档来自仓库原版基准，经转换器验证后生成，测试前需重新导入同一起点。触点与拖动手势属于运行时状态，不写入存档。
