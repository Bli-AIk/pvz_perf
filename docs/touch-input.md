# 触点输入

鼠标和触控是独立的输入来源，可以同时使用。触控事件携带稳定 ID 和逻辑坐标，不借用或临时改写全局鼠标位置。当前版本没有鼠标侧键模拟触控。

## 平台入口

Android 解码 MotionEvent 的 action index、pointer ID、移动、抬起和取消；窗口坐标经现有呈现区域映射到逻辑坐标。Windows 7 使用 RegisterTouchWindow／WM_TOUCH，一次读取关联的一批触点；Windows 10 使用 GetPointerFrameTouchInfo／SkipPointerFrameMessages 读取整帧并抑制重复消息。原生平台使用固定栈缓冲，游戏层最多十个捕获槽。

Win7 的编译分支不导入新版 Pointer API。输入记录解码后进入已有消息队列，控件回调仍在主线程执行。失焦、窗口取消、捕获丢失和超出固定缓冲范围均取消对应手势，不留下卡住的触点。系统由触摸合成的鼠标消息按标记过滤；真实鼠标移动恢复鼠标输入状态。

## 命中、悬停与按钮

按下时根据事件坐标命中控件，之后移动与松开仍交给该捕获控件；传给控件时转换为其局部坐标。用户列表和选卡 Menu 的点击不依赖鼠标悬停。触控不写入 WidgetManager／Board 的上次鼠标坐标。

触控输入关闭鼠标悬停高亮，真实鼠标移动重新启用。按钮仅在最初按下的触点仍位于按钮内时高亮，离开后熄灭；拖到另一个按钮不会点亮或触发它。按下与松开不是同一按钮时不触发。鼠标捕获与触点捕获相互独立。

## 共享植物与工具选择

鼠标和所有手指共用一个有效的植物／铲子选择；花园工具也采用唯一选择规则。植物同一时刻只允许一个拖动，另一根手指不会同时种另一株。轻点卡槽或拖放失败后保留选择，可以再点地种植；再次点击已选卡牌／铲子取消。换卡和换输入来源时归还旧来源并使旧手势不再提交。

种子雨与砸罐子的场上卡牌支持轻点保留、抖动容差、再次点击取消、换卡、归还来源和鼠标接手。保存前取消触点并归还预留卡牌，序列化的仍是真实鼠标 CursorObject；触点指针和手势不进入 DAT64，版本保持 v4。

## 加农炮与经过拾取

水族馆仅在空白处完成轻点后投喂脑子；拖动、取消或手势中拾取过阳光／金币都不投喂。拾取标记只由投喂规则读取，不复用全局的忽略抬起标记，因此经过收集物仍可种植、使用工具或发炮；买鱼卡和鼠标立即投喂保留原来的处理方式。两个手势布尔值利用触点结构的对齐空间，不进入 DAT64。

`Challenge::MouseDown` 的互斥模式分发采用类静态函数指针表，冒险关卡的 15／35 关共用锤僵尸／砸罐子的处理函数。表在 `.cpp` 编译期生成，没有逐实例缓存。公共场景限制、戴夫对话优先级和金币放行规则由同一个包装函数维护；花园直接分发，保持它先于场景限制处理的原有顺序。

玉米加农炮按手指独立捕获，可以同时拖动不同炮；同一炮不能被两个手指重复认领。必须从炮身拖动，移动距离不超过一格不发射，不保留“点一下选炮、再点目标”的触控准心。触控接入会取消鼠标待发炮准心，随后可重新从炮身开始触控拖动。

阳光、银币、金币、钻石和通关新植物／钱袋／奖杯在触点经过时独立拾取，仍调用原有结算逻辑，不抢走卡牌、铲子或炮的拖动目标。移动检测使用相邻事件坐标之间的线段，避免快速扫过遗漏；暂停或模态界面下不拾取。场上可用植物卡牌和普通花园盆栽礼盒不属于经过即拾取。

## 预览与绘制

鼠标与触控选中卡槽都显示蓝色四角框，不再因预留选择而把整张卡牌变暗；真实冷却、阳光不足和消失前闪烁保留。四角框已进入 CommonUIAtlas。卡槽／铲子／花园工具的框在底层 UI 提交，掉落卡牌的框跟随自己的 Coin::Draw；遮挡对象同时遮住卡牌和框，不增加独立排序项或全池扫描。拖动预览和炮准心保留顶层。

植物拖动仅在目标格可种植时显示整组横竖白色辅助带，屋顶按坡面格子绘制；绘制复用 CursorPreview 更新时已有的合法性结果，不重复调用 CanPlantAt。铲子不显示条带，只让即将铲除的目标植物发亮；花园工具作用目标也发亮。花园八类工具支持唯一选择、取消和切换，以及手套／手推车实际转移和树肥使用。

## 性能与验证

输入使用固定十槽，不创建输入线程；没有触控事件时不增加拾取扫描。空闲更新直接返回，框随既有对象提交。生产头文件只声明接口与数据，坐标和输入处理位于 .cpp。

实际生产对象回归覆盖双指独立结束、共享选择、嵌套保存、炮的重复／失效目标、扫过拾取、场上卡牌、花园、屋顶和 800／1400 宽度 GPU 像素读回。Windows 原生入口另测解码记录和合成鼠标过滤；它不等于 Win7 实机触屏已经验收。源素材与参考实现分别见 [TV 四角框](research/tv-selection-frame.md)、[Windows Phone](research/windows-phone-touch-input.md) 和 [Free](research/android-free-touch-input.md) 的调查。


## 横板 UI 试用

`settings.json` 的 `landscapeUI` 为布尔值，默认 `false`。退出游戏后改为 `true`，下次进入关卡生效。不自动检测触摸屏或切换输入设备；鼠标和触控仍共用已有的选中状态。Android 在窗口首次初始化时用实际宽高做一次 890:600 门槛判断，不足则静默使用电脑 UI，仍保留配置中的 true；过程中不每帧检测或切换布局。电脑全屏不足 890:600 时保持至少 890×600 的横板画布并上下补黑边，窗口模式维持最小 890×600。

横板布局将十个 81×53 横卡槽贴窗口左边排列，槽距 48 像素，原生 53 像素卡面的边缘／阴影相互叠放，不绘制侧栏蒙版；85×31 阳光栏也贴左上角，卡槽从 Y=33 开始，第十槽从 Y=465 开始，铲子在同列 Y=520，原生 84×41。选卡页采用四列横卡和 WP 的原生面板／按钮素材。绘制、命中、选框、冷却遮罩、选卡飞行动画与阳光收集终点使用同一组布局坐标。传送带保留原有运作数据，将卡牌的横向行进映射为向上行进；从 Y=33 开始的一段原生 93×480 外框容纳十槽，阳光栏独占上方空间，纹理与卡牌同向上移。拉霸的卡槽与吐卡、禅境花园和智慧树暂保留原来的专用布局；场上掉落卡牌仍用原有竖卡。拉霸阳光栏跟随全局布局开关，由 SeedBank::DrawSun 统一处理背景、数字缓存和不足阳光闪烁；收集阳光的终点跟随同一位置。

布局参考 Free／WP 的四列滚动选择，但采用本机 WP 移植包内的原生 PNG，以满足 800×600 下一点对一点：卡面 81×53、价格底片 33×20、面板顶部 371×44、中段 371×3、底部 371×24。素材来自 `wp移植版0.0.7.1.zip` 内的 `Assets.zip`，按公开 `AtlasResources_480x800.cs` 的区域无损裁出，没有重采样。英文标题从旧版 `1.5.3_Windows_x64.zip` 的英文 loc 图集中恢复；短阳光栏由 Free 原生图集裁取 85×31 区域，均不缩放。原始包、图集区域和像素哈希见[来源清单](../assets/source-art/landscape-ui/native-source.json)。模仿者卡面仅离线转换 RGB 灰度，尺寸和 alpha 不变。

UI 素材按用途分成三张独立图集：`common_ui` 放石头按钮、通用对话框、共用选卡按钮和蓝色选择框；`desktop_ui` 放电脑选卡背景、模仿者扩展底板和卡槽剪影；`landscape_ui` 放横板卡面、面板、按钮、阳光栏、铲子、传送带及黄色选框。桌面与横板专用素材分别由 `DesktopUI.atlas.dsl` 和 `LandscapeUI.atlas.dsl` 描述；共用按钮不因外观来自电脑版就重复打包。加载期按已经确定的 `mLandscapeUIActive` 加载共用加当前布局专用图集，未选布局的纹理不解码、不上传；三张图集均保留在统一 pak64 中。释放入口可安全清理未加载的空指针。没有新增全局 ImageSymbol，电脑选卡的三个旧全局图片绑定同时移除。绘制直接使用区域原尺寸；面板中段由 152 段 371×3 原图离线拼为 371×456 原生长条，运行时一次绘制，传送带按原尺寸循环，横板选框改用 WP `Dialog.png` 中 92×60 的黄橙双色原生四角，拆为四个 32×30 区域按卡槽／铲子边缘定位，不缩放；浅色内线、橙色轮廓和透明光晕保持原图像素。横板 HUD 位于 `COIN_BANK-1`，高于战场与雾、低于普通阳光／金币的 `COIN_BANK+1`，不修改收集物本身的顺序。选框按 53 像素卡面定位，不使用 48 像素槽距，底边避开价格。阳光栏数字中心为原图 X=53，四位数不再偏向右边框。模仿者按钮位于右侧独立扩展区，不在四列滚动牌表。IZ 僵尸卡由底框、加载期预生成的僵尸缓存图的原尺寸肖像裁片和价格组合，没有额外僵尸实例或动画更新。

`mLandscapeHud` 和就绪闪光起点只在运行时使用，不进入 DAT64。SeedBank／SeedPacket 的业务坐标和存档布局不变，因此切换 UI 不要求转换存档。FTZ／DAZ 的线程初始化继续保留，与 UI 开关互不依赖。

验证入口：`tools/test-image-runtime.ps1 -BuildDirectory out/x64-win32-vulkan -Case landscape-ui`。它使用实际 Release 对象和 PAK，检查 800／1067／1400 宽度下十卡槽的绘制／命中、触控选中与取消、传送带映射、选卡页和当前 DAT64 往返，并输出 GPU 读回截图。

选卡列表支持鼠标滚轮逐行滚动、触控拖动与松手惯性；成就页也支持触控惯性。开始拖动会停止先前惯性，越界钳制，取消手势会停止滚动；一次滑动不会选卡或按下返回／更多按钮。惯性按松手时刻、起点、初速度和恒定减速度直接求值，不受更新频率影响。拖动使用绝对触点位置，避免成就页控件自身移动后反过来改变手指位移。列表静止时不遍历重排卡牌，不改共享 WidgetManager 的鼠标／触控分发。

横板卡槽的冷却遮罩占据剩余的右侧区域，左边先恢复，右边最后恢复；价格底片和数字嵌在卡牌里面，并随卡面一起被冷却遮罩覆盖。原版竖卡及场上掉落的种子卡仍保持原来的绘制与冷却方向。

横板 UI 启用时，Windows 客户区最低为 890×600（有加载期缩放输出时按相同比例约束）。逻辑宽度从 800 到 900 时，横板 UI 先向左扩展、电脑 UI 先向右扩展；900 到 1000 补足另一侧，1000 到 1240 左右均分；左侧达到 220 像素上限后，新增宽度全部分配给右侧，直到右侧 380 像素上限。背景相机独立取景，不改变窗口 UI 的扩展规则。选卡面板从 Y=600 滑入，查看草坪时也完全滑出；模仿者弹窗内使用同样的原生横卡、四列滚动和触控惯性。

关闭最后一个弹窗时，若主选卡界面仍注册在 UI 树中，统一将焦点还给它，避免 Board 抢走滚轮事件；模仿者、Menu、图鉴和商店共用该逻辑。列表的显示、点击与滚动边界按石框实际整条平铺后的内框计算，不使用弹窗总高度；像素回归同时验证标题和底部边框不被卡牌覆盖。

布局复用原有 Board、SeedBank/SeedPacket、SeedChooserScreen 和 ImitaterDialog；卡牌不是新增的 Widget 节点。LandscapeHud 只提供原生图集绘制及统一的显示/命中几何，选卡页复用现有按钮实例。滚动只在输入或惯性活动时更新列表位置。选卡/冷却/拖拽等业务状态和 DAT64 不因布局改变。

电脑选卡列表复用现有滚动状态，滚轮按原生行距滚动，植物数未超出可视区时钳制为零；扩卡后的内容高度按选择枚举范围及列数计算。默认电脑列表静止时继续使用原绘制路径，有滚动时才增加列表局部裁剪。

横板布局及绘制路径在启动后固定。选卡列表用三份静态只读网格配置（电脑五行、电脑扩展、横板），仅创建或商店解锁变化时选择配置并计算滚动界限；模仿者的石框裁剪界限只在 Resize 时重算。战斗卡槽的传送带分类、共同裁剪和视口基准在每批绘制时计算一次，不再对每张卡重复计算。

横板 HUD 的矩形使用 Board 局部的窗口锚点（窗口边界减 Board 相机位移），绘制与命中共用同一矩形。背景相机独立保持完整原生背景可见，读档或窗口比例变化后修正静止位置；不改变实体世界坐标。21:9 使用完整 1400×600 画布；手机超过 21:9 时左右居中补黑边。

横板卡槽、传送带、铲子与选择框统一由顶部 HUD 阶段绘制，位于世界物体和 ABOVE_UI 收集物之后、全屏淡出之前，高于小推车、植物、僵尸等世界物体，暂停等模态弹窗仍在其上。电脑布局保留原绘制层级。

阳光收集模拟直接使用当前阳光栏的 Board 局部目标点，绘制时不再额外套一次旧的屏幕偏移投影。震动在视口的静止取景位置上叠加，而不是覆盖成围绕 x=0 的位移；结束时回到同一基准。未新增存档字段。
